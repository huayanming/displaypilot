CLI フラグ

参数作用
--list / --list-modes列出显示器与全部模式（含被系统隐藏的 HiDPI）
--set-brightness / --offset-brightness设置软件调光亮度 / 在当前值上增减
--set-temperature / --preset设置色温（2700–9000K）/ 应用场景预设
--set-resolution切换分辨率，优先 HiDPI
--dump-gamma / --reset读伽马表中点值（只读）/ 交回系统 ColorSync 校准
--login-item / --request-accessibility登录时启动 / 请求辅助功能权限
--scroll-report / --scroll-selftest滚动诊断 / 验证插值算法
--license-selftest / --cli-selftest授权状态机 / 参数模糊测试与脱敏断言
--switch-probe / --switch-selftest开关可用性（只读）/ 读切读回实测

意図的に行わないこと

  • 深色模式、勿扰、夜览、原彩显示、隐藏桌面：需要系统私有接口，公开 API 做不到。
  • Xcode 缓存清理与屏幕分辨率不做成一键：会真删数据或导致黑屏。
  • 锁键盘：会让键盘失去响应，不做一键。
  • 无遥测、无埋点、无账号系统。
