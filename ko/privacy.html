개인정보 처리방침

최종 업데이트: 2026년 10월 16일

한 문장으로: DisplayPilot은 텔레메트리도, 분석도, 사용 통계도 없습니다. 앱에 분석 SDK가 들어 있지 않고, '어떻게 썼는지'를 보내는 요청도 없습니다. 아래에 로컬에서 무엇을 읽고, 네트워크에 연결하는 것이 어느 세 가지뿐인지 명시합니다.

1. 수집하는 것

사용 데이터는 전혀 수집하지 않습니다. 분석도, 이벤트 전송도, 크래시 리포트 업로드도, 기기 지문도, 광고 식별자도, 사용자 프로파일링도 없습니다.

우리가 주도해서 보내는, 식별 정보를 포함하는 유일한 통신은 사용자가 직접 라이선스 키를 입력한 뒤 실행되는 라이선스 확인입니다. 보내는 내용은 정확히 두 가지입니다.

  • 라이선스 키 — 구매 이메일로 받아 직접 입력한 문자열.
  • 무작위로 생성된 기기 식별자 — 최초 활성화 때 로컬에서 UUID로 생성되어 macOS 키체인에 저장됩니다. 하드웨어 일련번호, MAC 주소, 디스플레이 EDID, 컴퓨터 이름, Apple ID, 계정 정보는 전혀 포함되지 않습니다.

이 무작위 식별자의 유일한 목적은 이 Mac이 이미 활성화 슬롯 하나를 차지했음을 판매자에게 알려, 하나의 라이선스 키가 무제한 기기에서 동시에 쓰이는 것을 막는 것입니다. 사용자 개인이나 기기 모델로 역추적할 수 없습니다.

현재 상태: 구매 채널이 개통되었습니다. 결제는 저희가 직접 운영하는 암호화폐 결제로 이루어집니다. DP- 라이선스 코드는 오프라인으로 검증되며 서버에 접속하지 않습니다. 네트워크 요청은 짧은 코드를 교환할 때 한 번뿐이고, 대상은 저희 서비스입니다(제3자가 아닙니다).

2. 수집하지 않는 것

다음은 앱이 사용하되 사용자의 Mac 메모리 안에서만 처리하고 절대 업로드하지 않는 항목입니다.

  • 디스플레이 모델, 벤더 ID, 제품 ID, EDID 전문과 물리 색역.
  • 해상도, 주사율, 현재 감마 테이블, 밝기와 색온도 값.
  • 디스크 용량, 캐시 디렉터리 크기, 스캔 결과와 정리 기록.
  • 창 제목과 위치(창 배치와 세션 복원에 필요하며, 손쉬운 사용 권한을 허용한 뒤에만 읽을 수 있습니다).
  • 휠 이벤트와 단축키 키 입력(스크롤 스무딩과 마우스 매핑에 필요).

그리고 다음은 아예 건드리지 않습니다.

  • 디스플레이 모델, EDID, 일련번호를 업로드하지 않습니다 — 그런 코드 경로 자체가 없습니다.
  • 사용 시간, 기능 클릭 횟수, 실행 횟수를 업로드하지 않습니다.
  • 키보드 입력을 기록하지 않습니다. 스크롤 스무딩이 읽는 것은 휠 이벤트의 이동량뿐입니다. 키보드는 '⌘를 누르는 동안 스무딩을 우회한다'는 한 가지 상태 판정에만 씁니다.
  • 마이크, 화면 기록, 전체 디스크 접근 권한을 요청하지 않습니다. 저장 공간 스캔은 읽기 전용이며, 시스템이 보호하는 디렉터리는 macOS 규칙대로 건너뜁니다.
  • 화면과 소리를 캡처하지 않습니다. 앱에 카메라나 마이크 호출이 없습니다. (Info.plist에 초기 화이트 포인트 비교 실험에서 남은 카메라 용도 설명이 하나 있지만, 대응하는 구현은 없습니다.)

3. 네트워크에 연결하는 것은 세 가지뿐

아래 세 가지를 제외하면 앱은 능동적인 네트워크 요청을 보내지 않습니다. 모두 HTTPS이며 평문 HTTP는 쓰지 않습니다.

1. 업데이트 확인

앱은 appcast.xml에 버전 목록을 한 번 요청해 새 버전이 있는지 판단합니다. 이 목록은 이 웹사이트와 함께 GitHub Pages에서 호스팅됩니다. 이 요청에는 라이선스 키도, 기기 식별자도, 사용 데이터도 없습니다. 또한 기본적으로 꺼져 있습니다: '일반' 패널에서 자동 확인을 직접 켰거나(이후 하루 최대 한 번), '업데이트 확인'을 직접 눌렀을 때만 전송됩니다.

호스트인 GitHub는 여느 웹 서버와 마찬가지로 IP 주소, 요청 시각, 클라이언트 식별자를 보게 됩니다. 이는 호스팅 서비스의 일상적인 접근 로그이며, 우리가 추가로 수집하는 것이 아닙니다.

2. 라이선스 확인

이것은 활성화할 때만 발생합니다. 긴 서명 코드(DP-…)는 앱에 내장된 공개 키로 로컬에서 오프라인으로 검증되며, 활성화할 때도 그 이후에도 Mac에서 요청이 나가지 않습니다. 짧은 코드(DP-XXXX-XXXX-XXXX)는 교환할 때 저희 서비스와 한 번만 통신합니다:

  • 짧은 코드 교환: 짧은 코드와 위에 설명한 무작위 기기 식별자를 보내고 긴 서명 코드를 받습니다.
  • 긴 서명 코드: 내장 공개 키로 오프라인 검증합니다. 계정 없음, 서버 없음, 주기적 통신 없음. 오프라인이었다는 이유로 만료되지 않습니다.

우리는 이를 의도적으로 오프라인 우선으로 만들었습니다. 재확인 실패, 연결 끊김, 서버 장애는 라이선스 상태를 바꾸지 않고 오류 한 줄만 기록합니다. 오랫동안 연결되지 않아도 7일의 유예 기간 동안 평소처럼 쓸 수 있습니다. 활성화하기 전에는 라이선스 요청이 전혀 전송되지 않고, 계정을 입력할 필요도 없습니다.

현재 상태: 이 단계는 적용됩니다. 긴 DP- 코드에는 네트워크가 전혀 필요하지 않습니다. 위의 짧은 코드 교환이 앱의 유일한 라이선스 요청이며 저희 서비스로 전송됩니다. 활성화하기 전에는 앱이 라이선스 요청을 보내지 않고 계정도 요구하지 않습니다.

3. 구매 페이지나 웹사이트 열기

'구매' 또는 '웹사이트 방문'을 클릭하면 기본 브라우저에서 열립니다. 결제는 앱이 아니라 브라우저에서 이루어집니다. 구매 입구는 저희 서비스가 제공하는 주문 페이지이며, 기존 브라우저를 사용하고 아무것도 설치하지 않습니다.

4. 데이터가 저장되는 곳

  • 라이선스 기록(라이선스 키, 인스턴스 ID, 활성화와 재확인 시각): macOS 키체인, 서비스 이름 com.neeson.displaypilot.license. 평문 plist가 아닙니다.
  • 앱 설정(체험 시작일, 인터페이스 환경설정, 단축키 지정, 자동화 규칙, 눈 보호 일정): ~/Library/Preferences/com.neeson.displaypilot.plist.
  • 정리 격리 영역과 작업 기록: ~/Library/Application Support/com.neeson.displaypilot/Clean/. 정리 대상 파일은 먼저 이곳 격리 영역으로 옮겨지고 30일 동안 언제든 복원할 수 있습니다.
  • 시스템 권한: 손쉬운 사용 권한은 macOS가 관리하며 '시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용'에서 언제든 취소할 수 있습니다.

완전히 지우려면: 앱을 종료한 뒤 위의 두 디렉터리/파일을 삭제합니다. 더 확실하게 하려면 키체인 접근에서 그 항목 하나도 지우십시오. 앱은 백그라운드 서비스나 데몬을 설치하지 않으며, 삭제 후에도 상주 구성 요소를 남기지 않습니다.

5. 제3자

  • 저희 라이선스 서비스(Cloudflare Workers): 주문 페이지 제공, 결제와 온체인 기록 대조, 라이선스 코드 발급, 짧은 코드 교환을 처리합니다. 주문 번호, 트랜잭션 해시와 금액, 무작위 기기 식별자를 보지만 이름, 이메일, 계정은 보지 않습니다.
  • 공개 블록체인 API(예: TronGrid 및 공개 RPC): 송금 확인을 위해 공개 체인 데이터를 읽습니다. 개인 데이터는 전송하지 않습니다.
  • GitHub: 이 웹사이트, 업데이트 매니페스트, 다운로드를 호스팅합니다. 호스트로서 일반 접속 로그(IP, 시각, 경로)를 보관합니다.

이 외에 이 앱과 이 사이트에는 분석 서비스, 광고 네트워크, 소셜 플러그인, 서드파티 글꼴이 없습니다.

6. 아동

DisplayPilot은 Mac 사용자를 위한 데스크톱 도구입니다. 아동을 대상으로 설계되지 않았고, 아동의 정보를 의도적으로 수집하지 않습니다.

7. 방침 변경

향후 버전에서 네트워크 동작이 바뀌면(예: 클라우드 동기화 추가) 이 방침을 먼저 갱신하고 변경 사항을 변경 기록에 적습니다. '계속 사용하면 동의한 것으로 본다'는 문구로 수집 범위를 조용히 넓히지 않습니다. 구매 채널이 열리면 이 페이지와 사용권 계약을 함께 갱신해 그때 실제로 효력을 갖는 동작을 설명합니다.

8. 문의

이 방침에 대한 질문이 있거나 보관 중인 라이선스 정보를 확인하려면 GitHub에서 이슈를 열어 주세요.
