隐私政策

最后更新：2026 年 10 月 15 日

一句话：DisplayPilot 不做遥测、不做埋点、不做使用统计。 应用里没有接任何统计 SDK，也没有一条会把你「怎么用它」发出去的请求。 下面把它在本地读什么、真正联网的只有哪几件事，逐条写清楚。

一、我们收集什么

不收集任何使用数据。没有埋点、没有事件上报、没有崩溃日志上报、没有设备指纹、没有广告标识符、没有用户画像。

唯一一次由我们主动发起、并且会带上识别信息的联网行为，是你主动输入授权码之后的许可校验。它发送的内容只有两项：

  • 授权码（license key）——你自己在购买邮件里收到、并手动输入的那串字符；
  • 一个随机生成的设备标识——首次激活时由应用在本地用 UUID 生成，存放在系统钥匙串里。 它不包含硬件序列号、MAC 地址、显示器 EDID、机器名称、Apple ID 或任何账号信息。

这个随机标识的唯一用途，是让商户知道「这台 Mac 已经占用了一个授权名额」，以免同一枚授权码被无限台机器同时使用。它无法反查到你本人，也无法反查到你的设备型号。

二、我们不收集什么

下面这些数据应用会用到、但只在你本机内存里处理，永远不上传：

  • 显示器型号、厂商 ID、型号 ID、EDID 全文与物理色域；
  • 分辨率、刷新率、当前伽马表、亮度与色温数值；
  • 磁盘容量、缓存目录大小、扫描结果与清理记录；
  • 窗口标题与窗口位置（窗口布局与会话恢复需要，要你授权辅助功能后才读得到）；
  • 滚轮事件与热键按键（滚动平滑、鼠标映射需要）。

另外这些我们根本不碰：

  • 不上传显示器型号、EDID 或序列号——从来没有这类代码路径；
  • 不上传使用时长、功能点击次数或启动次数；
  • 不记录键盘输入。滚动平滑只读取滚轮事件的位移量；键盘只用于判断「按住 ⌘ 时绕过平滑」这一个状态；
  • 不申请麦克风、屏幕录制与全盘访问权限。存储扫描是只读的，受系统保护的目录按 macOS 的规则直接跳过；
  • 不采集画面与声音。应用里没有任何摄像头或麦克风调用。 （Info.plist 中仍留有一条历史摄像头用途声明，是早期白点比对实验的残留，它没有任何对应的实现。）

三、真正联网的只有三件事

除了下面三项，应用不会主动发起任何网络请求。全部走 HTTPS，不使用明文 HTTP。

1. 检查更新

应用会向 appcast.xml（托管在 Cloudflare Pages）请求一次版本清单，用于判断有没有新版本。 这个请求里不含授权码、不含设备标识、不含任何使用数据。 它默认是关闭的：只有你在「通用」面板里主动打开自动检查（此后每天最多一次）， 或者手动点一次「检查更新」，才会发出这个请求。

托管方 Cloudflare 与任何网站服务器一样，会看到你的 IP 地址、请求时间和浏览器／客户端标识。这是托管服务的常规访问日志，不是我们额外采集的。

2. 校验授权

只有在你输入授权码之后才会发生。请求发往商户 Lemon Squeezy 的授权接口（api.lemonsqueezy.com/v1/licenses）：

  • 激活：发送授权码 + 上面那个随机设备标识；
  • 定期复核：激活成功后每 30 天复核一次，发送授权码 + Lemon Squeezy 返回的实例编号；
  • 取消激活：同样两项，用于释放名额，让你把授权换到另一台 Mac。

我们特意做成离线优先：复核失败、断网、服务器故障都不会改变你的授权状态，只会记下一条错误；万一复核长期不通，还有 7 天宽限期照常使用。 没激活之前，应用不会发出任何许可请求，也不需要填任何账号。

3. 打开购买页或官网

点「购买」或「访问官网」时，地址会在你的默认浏览器里打开。付款在你的浏览器中完成，不经过应用。

四、你的数据存在哪里

  • 授权记录（授权码、实例编号、激活与复核时间）：macOS 系统钥匙串，服务名 com.neeson.displaypilot.license。不是明文 plist。
  • 应用设置（试用起始日期、界面偏好、热键绑定、自动化规则、护眼排程）：~/Library/Preferences/com.neeson.displaypilot.plist。
  • 清理隔离区与操作台账：~/Library/Application Support/com.neeson.displaypilot/Clean/。 被清理的文件先移进这里的隔离区，30 天内可随时还原。
  • 系统权限：辅助功能授权由 macOS 管理，可在「系统设置 → 隐私与安全性 → 辅助功能」里随时撤销。

删除方式：退出应用后，把上面两个目录／文件删掉即可；想要更彻底，再在钥匙串访问里删掉那一条记录。应用不在系统里安装任何后台服务或守护进程，卸载不留下常驻组件。

五、第三方

  • Lemon Squeezy（商户记录方）：处理支付、发票与全球增值税。你在购买时提供的邮箱和支付信息由他们收集与保存，我们只能看到订单号、邮箱和授权码。他们的隐私政策适用于这些数据。
  • Cloudflare：托管本网站与安装包下载。作为托管方会按常规记录访问日志（IP、时间、请求路径）。

除此之外，本应用与本站点没有任何分析服务、广告网络、社交插件或第三方字体。

六、儿童

DisplayPilot 是面向 Mac 用户的桌面工具，不面向儿童设计，也不会有意收集儿童的任何信息。

七、政策变更

如果未来的版本改变了联网行为（例如新增了云同步），这份政策会先更新，并在更新日志里写明改了什么。我们不会用「继续使用即视为同意」来悄悄扩大收集范围。

八、联系方式

对这份政策有疑问，或想核对你被保存了哪些授权信息，写信到 GitHub Issues。
