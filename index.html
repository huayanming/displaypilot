01 · Smooth scrolling

One notch, split into a stroke

A wheel notch stops being a single jump. Events are accumulated, then delivered on every display refresh — each frame emitting pending × (1 − e^(−dt/τ)). Because the decay is driven by elapsed time rather than by frame count, 60 Hz and 144 Hz feel the same. In our offline benchmark, the first frame at 120 Hz improved from 3 points to 9, and time-to-90% fell from 158 ms to 133 ms.

Windows that treat the wheel as a precision input or a zoom control — terminals, image viewers, slide decks — are handed back to the system by default. Hold ⌘ at any time to return to native scrolling. Smoothing ships off: it never takes over your wheel unless you turn it on. The interface keeps four live counters — seen, gesture, intercepted, delivered — so when a new mouse misbehaves, you can see exactly which layer is dropping it.

02 · Software dimming

Dim without touching panel firmware

Brightness runs through the CoreGraphics gamma table, so it works even on monitors that don't implement DDC/CI. Every write is read back and compared; when they disagree the app backs off and retries, up to four times. Resolution changes and wake-from-sleep replay the curve automatically, so it never silently stops working.

Replays always recompute from the panel's original baseline rather than from the current curve, so repeated adjustment can't accumulate error — measured, the mid-gray point moved from 0.5020 to 0.3012. macOS restores the display when the process exits, and there are two recovery paths that don't require the app to be running: one inside the app, and Scripts/restore-dimming.sh.

03 · Color calibration

Anchored to the curve read when the app first takes over

Contrast pivots on mid gray, gamma works the midtones, and color temperature spans 2700–9000 K — all three computed from the panel's original curves. 6500 K is anchored as the identity transform, so the default state is exactly how your display already looks.

The physical gamut is read straight from the EDID and drawn as a CIE xy triangle, placed next to its coverage of sRGB and Display P3. What can align, aligns; the parts the panel physically cannot reach — high-saturation red and green — are labeled as out of reach instead of faked. One click hands calibration back to ColorSync.

04 · Safe cleanup

Quarantine first. Delete later.

It only touches 13 categories of artifacts that have a deterministic way to be rebuilt: Xcode DerivedData, SwiftPM, CocoaPods, npm / pnpm / Yarn, Go, Gradle, Rust target, __pycache__, crash reports, Homebrew caches, and the like. Anything removed is moved into quarantine first, kept for 30 days by default, and restorable at any time.

Permanent deletion is off by default. Exactly one function in the whole app can do it, and it proceeds only when six conditions hold at once — fail any one and it aborts. The app doesn't request Full Disk Access; system-protected directories are skipped per macOS rules. Automation rules can pre-scan, never delete.

Session restore

Save your displays, windows, audio, scrolling, mouse, and eye-care settings as a named snapshot, restored domain by domain. Before restoring, it lists exactly what will change and waits for confirmation. If a domain is unavailable it skips that domain instead of failing the whole restore.

Inputs and the hardware channel

When the display speaks DDC/CI, switching HDMI / DisplayPort no longer means reaching for the OSD buttons, and hardware brightness, contrast, and volume sit in the same panel. When it doesn't, the app says “DDC not responding” and keeps working through the software channel — it doesn't pretend to succeed.

Accessibility

Every slider and switch exposes an accessibility label and appears in the accessibility tree, and interface text was reworked to a 4.5:1 contrast baseline (the worst case was 2.65:1 before). Global hotkeys: ⌃⌥↑ / ⌃⌥↓, with ⇧ for ±1% fine-tuning.
