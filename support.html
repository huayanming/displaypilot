遇到问题先看下面的常见问题。需要联系我们时，请用应用内 「通用 → 关于 → 报告问题」生成诊断信息，检查后连同问题描述一起发送。 应用不会自动收集或上传任何内容。

常见问题

1. 为什么我的显示器 DDC 无应答？

因为这块面板没有实现 DDC/CI（显示器控制命令集）。这不是应用的问题：有些显示器、电视、扩展坞与转接器根本不响应这类命令，我们用于测试的 UP32R7-A 就是其中之一。

此时硬件亮度、硬件音量与输入源切换不可用；应用会明确标注「DDC 无应答」，并自动把亮度交给软件调光（通过 CoreGraphics 伽马表压暗画面）。软件调光一样能把屏幕调暗，但它不改变面板背光电流，所以省电幅度与硬件调光不同。

2. 平滑滚动和 Mos / Mac Mouse Fix 冲突怎么办？

这类工具都是通过拦截滚轮事件来做平滑的，同时开启会互相吞掉对方的滚轮。应用会在启动与运行中检测同类工具并提示冲突。处理办法（任选其一）：

  • 只保留一个平滑工具；
  • 在「滚动」面板里把本应用的滚动平滑关掉，或反过来关掉另一个工具；
  • 保留两者时，用「安全模式」：按住 ⌘ 滚动会临时交回系统；看图、PPT、地图这类把滚轮当缩放的窗口也会自动交回系统。

3. 怎么恢复显示器的原始状态？

从轻到重，按顺序试：

  1. 应用内还原：「显示」面板底部 →「还原此显示器」或「交回系统校准」。菜单栏图标里也能找到。
  2. 不依赖应用：在终端运行 bash Scripts/restore-dimming.sh。它把亮度、色温、预设写回中性值，不需要应用正在运行。
  3. 显示排列卡住 / 外接显示器不识别：需要管理员密码。删除系统级显示配置后重启： 
    sudo rm /Library/Preferences/com.apple.windowserver.displays.plist
rm -f ~/Library/Preferences/ByHost/com.apple.windowserver.displays.*.plist
sudo shutdown -r now
    只删用户级不够 —— 真正存显示排列的是系统级那个文件；删完必须重启。
  4. 完全进不了系统：关机 → 长按电源键 → 选项 → 终端，运行 emergency-restore-display.sh（在安装目录的 Scripts 下）。

这些恢复路径是刻意做成不依赖应用的。我们曾在测试中把显示器弄黑过，所以「能恢复」是产品的硬性要求，不是附赠功能。

4. 试用结束后哪些功能还能用？

试用期（14 天）内功能完整。试用结束后只暂停 5 项增强功能：滚动平滑、鼠标按键映射、护眼排程、自动化规则、会话保存与恢复。

恢复类操作永远可用，且不依赖联网：还原此显示器、交回系统校准、显示器休眠、退出、许可页面、关于页面、卸载/重置入口。换句话说，欠费不会把你锁在一块无法恢复的屏幕前。

5. 怎么在一台新 Mac 上激活？

  1. 在新 Mac 上打开「通用 → 许可」，输入购买邮件里的授权码，点激活；
  2. 如果提示激活名额已满，请在旧 Mac 上打开同一个页面，点「取消激活」释放名额，再回到新 Mac 激活。取消激活只移除本机授权，不影响你的购买。

可同时激活的台数由授权服务端决定，购买页会写明当前名额。

6. 清理功能会不会删错东西？

设计上就是把「删错」的概率压到最低：

  • 只处理 13 类有确定性重建方式的产物（Xcode DerivedData、SwiftPM、CocoaPods、npm/pnpm/Yarn、Go、Gradle、__pycache__、Rust target、崩溃报告、Homebrew 缓存等）；
  • 永不参与清理：文稿、桌面、下载、图片、影片、音乐、偏好设置、Application Support、钥匙串、邮件、信息、Safari；
  • 删除前先移入隔离区，默认保留 30 天，随时可还原；
  • 永久删除默认不存在：全应用只有一个函数能永久删除，必须同时满足 6 个条件，任何一条不过就中止；
  • 自动化规则只能预扫描，不能删除。

7. 你们会自动收集我的信息吗？

不会。应用不做遥测、不做埋点、不上传使用数据，也不自动上传崩溃日志。「报告问题」生成的内容只在你本机，必须由你手动复制或发送。真正联网的只有三件事：检查更新（默认关闭）、校验授权（激活之后才有），以及你主动点击时打开网页。详见隐私政策。

怎么报告问题

  1. 打开「通用 → 关于 → 报告问题」，点一下生成诊断信息；
  2. 自己看一遍内容（它会移除序列号、用户名、文件路径与授权码，但你仍应确认）；
  3. 点「复制到剪贴板」，把内容连同问题描述发到 GitHub Issues。

附上崩溃日志（如果应用崩溃过）

  1. 打开「应用程序 → 实用工具 → 控制台」；
  2. 左侧选「崩溃报告」（Crash Reports）；
  3. 找到 DisplayPilot 的条目，右键 → 在访达中显示；
  4. 把对应时间点的 .ips 文件作为附件发给我们。

日志的常见位置是 ~/Library/Logs/DiagnosticReports/。

我们做不到的事

  • 不能在不支持 DDC/CI 的显示器上提供硬件亮度/音量/输入源；
  • 不能保证软件调光与硬件调光的观感完全一致；
  • 不能替你操作 macOS 的显示排列，恢复需要按上面的步骤执行；
  • 无法直接办理退款（由 Lemon Squeezy 作为商户记录方处理）。
